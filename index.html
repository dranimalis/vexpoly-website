Python · pygame-ce · MIT

No engine. Just Python. And math.

VEXPOLY is a first-person arena shooter written in a single Python file. The camera, the clipper, the lighting, the fog — all written by hand, then handed to pygame.draw.polygon.

Renderer

A 3D pipeline
written in Python.

Camera transform. Near-plane clipping. Perspective projection. Backface culling. Directional lighting. Distance fog. Depth sorting. A per-frame polygon budget. All of it runs in Python, per frame.

01

Three objects, one loop

Cube, octahedron, pyramid. Each goes through the exact same transform → clip → project → cull → light → sort → draw chain, every frame.

02

No GPU involved

There is no shader and no vertex buffer. Every frame is Python walking over a list of polygons and filling them in.

03

Fog, light, sort

Lambertian lighting from a fixed direction, exponential fog over camera distance, and painter's-algorithm depth sorting.

Pipeline

Camera. Clip. Sort. Draw.

Every frame runs through the same eight stages. No shortcuts, no corners cut, no graphics API.

01 — 03

Camera transform & projection

Yaw, pitch, translation into view space, then a perspective divide. The result is a flat 2D coordinate per vertex.

04

Near-plane clipping

Polygons that cross the camera plane get cut before they can flip inside out.

05

Backface & frustum culling

Anything pointing away from the camera, or outside the view, is dropped before lighting runs.

06

Directional lighting

One fixed light vector, one dot product per face. Cheap, consistent, readable.

07

Distance fog

Camera-space depth drives a fade toward the sky colour, so far geometry melts into the horizon.

08

Depth sort & draw

Faces are sorted back-to-front by average camera-space depth, then handed to pygame.draw.polygon one by one.
