The pipeline

Eight stages. No shortcuts.

Every frame walks the same path. Nothing is handed off to a GPU, and nothing is hidden behind a library.

01 — 03

Transform & project

Yaw, pitch, translation into view space, then a perspective divide. One flat coordinate per vertex.

04 — 05

Clip & cull

Near-plane clipping cuts polygons that cross the camera. Backface and frustum culling drop the rest.

06 — 08

Light, fog, draw

Lambertian lighting, exponential distance fog, painter's-algorithm depth sort, then pygame.draw.polygon.

Overview

One file. One loop.

The whole game — engine, arena, weapons, UI — lives in vexpoly.py. No packages, no plugins, no build step.

No GPU involved

There is no shader and no vertex buffer. Every frame is Python walking a list of polygons and filling them in.

No hidden dependencies

Only pygame-ce and the Python standard library. No numpy, no OpenGL, no external maths.

Readable by design

Every stage is a short, self-contained function. The whole renderer fits in under a thousand lines.
