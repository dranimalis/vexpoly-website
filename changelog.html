Changelog

Release history.

Every notable change since v3.0.0. Full commit history lives on GitHub.

v3.4.2

2026.10.14 Latest
  • Build First release with pre-built binaries for Windows 10+, macOS Intel and Apple Silicon, and Linux x86_64.
  • Build Added the Windows executable, two macOS ZIPs, and Linux AppImage.
  • Verify Added SHA-256SUMS to verify downloaded files.

v3.4.1

2026.10.13
  • Fix Clamped sky projection at extreme camera pitch to prevent full-screen flashes.
  • Fix Capped ground subdivision and tightened its distance and area thresholds.
  • Render Culls off-screen polygons before sorting and drawing.
  • Perf Caches scaled blob shadows and reuses gradients at native render scale.
  • Render Corrected bloom to use a bright-pass and reduced distant outline passes.

v3.4.0

2026.07.19
  • Added Borderless fullscreen toggled with F11.
  • Added Fullscreen setting persists and is applied at startup.
  • Fix Pistol and shotgun now fire correctly on click.
  • Changed Centralized the game version in a VERSION constant.

v3.3.2

2026.06.04
  • Fix Uses consistent default font rendering across platforms.
  • Fix Removed the overly dark double vignette.
  • Render Bloom switched to a bright-pass implementation.

v3.3.1

  • Fix Reallocates render surfaces when a new run resets render scale.
  • Fix Implements the previously ignored glow flag in geometry emission.

v3.3.0

2026.04.22
  • Fix Polygon budget now keeps the closest polygons.
  • Fix Ground bounds use floor and ceiling correctly; near-plane distance and screen-coordinate clamping prevent close-up texture warping and runaway polygons.
  • Perf Adaptive render scale changes in steps instead of oscillating every frame.

v3.2.0

2026.02.11
  • Added Adaptive render scale and polygon budget driven by a rolling frame average.
  • Added Distance fog, bright-pass bloom, color grading, vignette, scanlines, and damage effects.
  • Added Five themes, three weapons, four enemy types, boss waves, and three game modes.
  • Added Four difficulty settings, achievements, combo scoring, kill feed, and damage direction indicator.

v3.0.0

2025.10.18
  • Render Introduced the custom software-rendering pipeline: camera transform, near clipping, perspective projection, backface culling, texture sampling, and depth sorting.
  • Game Added the ground grid, crates, pillars, billboard particles, basic enemy AI, and survival waves.
