Changelog

Release history.

Every notable change since v3.0.0. Full commit history lives on GitHub.

v3.4.2

2026.10.14 Latest
  • Build macOS builds for both Intel and Apple Silicon.
  • Build Windows 64-bit executable published via PyInstaller.
  • Build Linux x86_64 AppImage published.
  • Build SHA-256SUMS file attached to every release.

v3.4.1

2026.10.13
  • Perf Fog curve rewritten; 12% fewer draw calls per frame.
  • Render Depth sort now uses face centroid instead of vertex average.
  • Fix Near-plane clipping no longer leaks a stray vertex at low framerates.
  • Docs README rewritten with a pipeline diagram.

v3.4.0

2026.07.19
  • Game New arena: Warehouse 9.
  • Game Three weapons, each with distinct recoil profiles.
  • Game Sprint and jump reworked for higher momentum.
  • Perf Polygon budget raised to 2600 faces per frame on desktop.

v3.3.2

2026.06.04
  • Fix macOS build no longer crashes on launch under Rosetta.
  • Perf Backface culling uses a pre-computed normal cache.

v3.3.0

2026.04.22
  • Themes Toxic theme retextured end to end.
  • Themes Light direction now configurable per theme.
  • Render Fog gain and offset moved into the theme definition.

v3.2.0

2026.02.11
  • Render Near-plane clipping now runs on the quad, not the triangle.
  • Render Perspective divide batched into a single list comprehension.
  • Fix Offscreen faces are no longer sorted.

v3.1.0

2025.12.03
  • Game New weapon: the Repeater.
  • Game Ammo pickups.
  • Themes Arctic theme added.

v3.0.0

2025.10.18
  • Render Full pipeline rewrite — the renderer is now the code path it uses today.
  • Render Directional lighting replaces the flat shade.
  • Render Distance fog added.
  • Themes Industrial and Void themes.
