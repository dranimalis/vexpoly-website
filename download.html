Or run from source.

The full game is a single Python file. Clone it, install pygame-ce, and go. Works on Windows, macOS, and Linux.

quickstart.sh 
$ git clone https://github.com/dranimalis/vexpoly.git
$ cd vexpoly
$ python3 -m venv .venv
$ source .venv/bin/activate    # Windows: .venv\Scripts\activate
$ pip install -r requirements.txt
$ python vexpoly.py
